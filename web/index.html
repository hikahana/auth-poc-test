2. 名簿（ホワイトリスト）

  
ログインできるのは ….nutfes@gmail.com のアドレスだけです。それ以外は自動で拒否され、名簿にも残りません。
  .nutfes の人は、初めてGoogleログインした時点で「メンバー」として自動で名簿に登録されます（登録欄に「自動登録」と出ます）。
  名簿の人を締め出すときは「無効化」します。無効化した人は再ログインしても再登録されず、各プロダクトのセッションも消えます。

  
名簿を操作できるのは役割が「管理者」の人だけです（GM2やFinanSuの権限とは無関係）。最初の管理者は
  go run ./cmd/seed-admin <email> で登録します。最後の1人の管理者は無効化・降格できません。

3. プロダクト（認証基盤を呼べるサービス）

  
ここに登録されたプロダクトだけが、ログイン確認（/v1/auth/verify）を呼べます。
  登録すると発行されるIDと秘密鍵を、そのプロダクトのサーバーの環境変数
  （AUTH_PLATFORM_CLIENT_ID / AUTH_PLATFORM_CLIENT_SECRET）に設定します。管理者のみ操作できます。

  
通知先URLには、名簿から削除した人（または強制ログアウトした人）のセッションを消すよう、認証基盤が署名付きで通知します。
  未設定のプロダクトには通知されず、結果に「skipped」と出ます。
