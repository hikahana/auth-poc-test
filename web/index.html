  役割が「管理者」の人が「1.」でGoogleログインしているときだけ、名簿を操作できます（管理者は名簿の管理ができるだけで、GM2やFinanSuの権限とは無関係です）。
  最初の管理者は go run ./cmd/seed-admin <email> で登録します。最後の1人の管理者は削除・降格できません。
